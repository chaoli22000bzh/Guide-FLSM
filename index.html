Je connais l’adresse réseau initiale, son préfixe et son broadcast. Je vais apprendre à découper ce réseau en plusieurs sous-réseaux de même taille.

01 Je découpe mon réseau

Je vais remplir la partie B, puis la partie C de ma fiche d'adressage, une action après l'autre. Je commence par les bits empruntés : c'est ma méthode pour construire les sous-réseaux.

A · Je comprends pourquoi je découpe le réseau

J'ai besoin de plusieurs réseaux pour mes VLAN

Une entreprise veut séparer ses équipements dans 5 VLAN. Dans notre exemple, chaque VLAN aura son propre sous-réseau IPv4. Il me faut donc 5 sous-réseaux.

Le FLSM signifie que tous les sous-réseaux ont la même taille. Mais le nombre de sous-réseaux possibles avance par puissances de 2 : 2, 4, 8, 16… Pour en attribuer 5, je dois en créer au moins 8.

Créés par le découpage8
Encore disponibles3

Les 3 sous-réseaux non attribués restent disponibles pour plus tard : ils ne disparaissent pas.

Un sous-réseau disponible n'est pas la même chose qu'une adresse hôte encore libre dans un VLAN déjà attribué.

B · Je relève les données de départ

Je lis l'énoncé avant de calculer

Je recopie l'adresse réseau initiale, son broadcast et son préfixe. J'indique combien de sous-réseaux sont demandés. Dans notre exemple : 172.16.0.0/20, broadcast 172.16.15.255, et 5 sous-réseaux.

C · Je calcule les bits empruntés et le nouveau préfixe

Je cherche la première puissance de 2 suffisante

Je pars de 1 et je double jusqu'à obtenir au moins le nombre de sous-réseaux demandés. Pour 5 : 2¹ = 2 (pas assez), 2² = 4 (pas assez), 2³ = 8 (suffisant). J'emprunte donc 3 bits.

Je les ajoute au préfixe initial : /20 + 3 = /23. Je remplis les trois cases correspondantes en haut de la partie B de ma fiche.

D · Je remplis d'abord les bits empruntés

Je numérote mes sous-réseaux à partir de 0

Je conserve les 20 bits du réseau initial. Juste après, je repère les 3 bits empruntés : ils servent à numéroter les sous-réseaux. Dans notre exemple /20 vers /23, ces trois bits se trouvent dans le 3e octet.

Je commence par écrire 000 pour le sous-réseau 0, puis 001 pour le 1, 010 pour le 2, etc. Ce sont ces chiffres que je remplis en premier dans le tableau de la fiche.

Quand plus de 6 sous-réseaux sont demandés, je conserve les 3 premiers et les 3 derniers. Le saut dans la numérotation est volontaire : je ne recommence pas à zéro.

E · Je complète les adresses réseau et broadcast

Je remplis les quatre lignes de chaque sous-réseau

1. Je garde les bits fixes du réseau initial et les bits empruntés du sous-réseau choisi. Pour l'adresse réseau, je mets tous les bits hôtes à 0.

2. Je convertis cette adresse réseau en décimal, octet par octet.

3. Pour le broadcast, je conserve les mêmes bits réseau et les mêmes bits empruntés, puis je mets tous les bits hôtes à 1.

4. Je convertis le broadcast en décimal. Je retrouve exactement les quatre lignes demandées sur ma fiche.

Pour le sous-réseau 0 de notre exemple : réseau 172.16.0.0 et broadcast 172.16.1.255. Pour le sous-réseau 1 : réseau 172.16.2.0 et broadcast 172.16.3.255.

Je révèle les sous-réseaux un par un

Sous-réseauRéseau (binaire)Réseau (décimal)Broadcast (binaire)Broadcast (décimal)

Les cases binaires correspondent aux 32 bits de la fiche papier. Les points séparent les quatre octets pour faciliter la lecture.

F · Je calcule les hôtes utilisables par sous-réseau

Je remplis la partie C de ma fiche

Je prends le nouveau préfixe de sous-réseau, et non le préfixe initial. Je calcule le nombre de bits hôtes : 32 - préfixe du sous-réseau. Puis j'applique la formule 2^(bits hôtes) - 2. Les deux adresses retirées sont l'adresse réseau et le broadcast.

J'ai terminé la partie droite de ma fiche. Je peux maintenant choisir un niveau pour m'entraîner.
